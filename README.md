# Frontend Mentor Challenge

This is a solution to a challenge from [Frontend Mentor](https://www.frontendmentor.io/). The challenge is based on creating a responsive webpage using **HTML**, **CSS**, **Flexbox**, **CSS Grid**, and **SASS**.

## Overview

In this challenge, I was tasked with building a **responsive layout** based on a given design. The project makes use of modern web technologies like **Flexbox**, **CSS Grid**, and **SASS** to ensure the page is responsive, mobile-first, and cleanly organized.

You can view the live version of the project [here](https://oraby2002.github.io/personal-website/).

## Technologies Used
- **HTML**: Structure and semantic markup of the webpage.
- **CSS**: Styling for the layout, including typography, colors, and responsiveness.
- **Flexbox**: Used for creating flexible layouts that adapt to different screen sizes.
- **CSS Grid**: Utilized for more complex grid-based layouts to ensure the design is well-structured.
- **SASS**: A preprocessor that allows for more efficient and modular CSS.
